# Week 1 Web Development Projects

This repo contains all 7 projects built during Week 1 of the web development course.

## Projects

| # | Project | Tech |
|---|---------|------|
| 01 | Personal Portfolio | HTML, CSS |
| 02 | Responsive Navbar | HTML, CSS |
| 03 | Form Validation | HTML, CSS, JS |
| 04 | E-commerce Landing Page | HTML, CSS |
| 05 | Flexbox / Grid Layout | HTML, CSS |
| 06 | React Components Practice | React |
| 07 | React Blog UI | React |

## How to run

- Projects 01–05: Just open the `index.html` file in a browser.
- Projects 06–07: Run `npm install` then `npm start` inside the project folder.
